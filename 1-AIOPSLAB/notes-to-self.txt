- agents should be able to handle the full incident lifecycle - make it self-healing

steps:
[microservices] <--> connect to [agent/humans] --> incident detection -> triage after localization -> root cause diagnostics -> Mitigation/Resolution --> (goes back to agent)

- They create “problems”. Each problem is a realistic incident inside a running microservice system. They add faults with real root causes, like misconfigurations.

- Test apps: two apps from DeathStarBench (SocialNetwork and HotelReservation), with their workload generators.
- tools used: their own fault library, plus ChaosMesh.


- Telemetry:
    Prometheus for metrics
    Jaeger for traces
    Filebeat + Logstash for logs

Control: Helm and the Kubernetes API, used by the orchestrator.
